# Blender-Modeling-Sound-Extension

A Blender add-on that plays a sound while you model. Every extrude goes "blup blup", and the sound is yours to choose.



\## Features

\- Sounds for finished operations: extrude, bevel, inset, loop cut, delete, merge, duplicate

\- Your own mp3 / wav / ogg per rule, with volume and pitch controls

\- Add your own rules: match any operator by keyword

\- Live sound while scrolling the segment count of Bevel and Loop Cut (pitch rises per segment)

\- Built-in synthesized sounds, no files required



\## Install

1\. Download `extrude\_blup.py`

2\. Blender > Edit > Preferences > Add-ons > Install from Disk

3\. Enable "Extrude Blup" and open its preferences to set up your sounds



\## Notes

\- Sounds for finished operations play when the operation is confirmed, not when it starts.

\- The live segment sound is experimental and depends on your Blender version.
